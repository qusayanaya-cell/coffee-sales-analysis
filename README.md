# Coffee Sales Analysis

A small data science project exploring coffee shop sales data with Python.

## Dataset
`Coffe_sales.csv` has about 3,500 sales with these columns:
- Time_of_Day
- money
- coffee_name
- Weekday
- cash_type

## What I did
- Loaded and explored the data with **pandas**
- Plotted sales amount by weekday with **seaborn**
- Built an interactive version with **Bokeh**, with hover tooltips showing payment type and coffee name

## Tools
Python, pandas, seaborn, Bokeh, Jupyter Notebook

## How to run
1. Clone this repo
2. Install the libraries: `pip install pandas seaborn bokeh jupyter`
3. Open the notebook in Jupyter and run all cells
